# 外源数据接入模块 · 规格说明

> 本文档用于把当前的一次性脚本重写为模型内的正式模块。
> 数据本身的定义见 `README_资产说明.md`；本文档只讲**实现要求、接口契约与踩坑记录**。

---

## 1 模块职责

把一批政务记录补充为「带地理位置」的记录，并产出行政区划到位置的映射。

| 项 | 内容 |
|---|---|
| 输入 | 记录集合：`表名 / 记录ID / 名称 / 区县 / 街道或地址` |
| 输出 1 | **坐标长表**（资产一同构）：每条记录一行，含坐标、精度等级、可信标记、不可信原因 |
| 输出 2 | **行政区划映射表**（资产二同构）：`(区县, 行政区划) → 中心坐标` |
| 输出 3 | **接入状态**：`成功 / 弱定位 / 失败`，供下游决定是否参与距离判定 |
| 不做 | 不提供标签、不反推对端、不修改原始记录 |

## 2 接口契约

```python
class ExternalGeoEnricher:
    """外源地理补全器。所有输出必须可缓存、可断点续跑、可离线复现。"""

    def __init__(self, key: str, cache_dir: str,
                 qps_interval: float = 0.15,
                 hard_timeout: float = 8.0): ...

    # ---- 原子接口 ----
    def geocode(self, address: str, city_adcode: str | None = None) -> GeoHit | None:
        """地址 → 坐标。city_adcode 必传（决定跨省错配率）。"""

    def regeo(self, lng: float, lat: float) -> dict | None:
        """坐标 → 地址。仅用于坐标系判定与复核，不产出资产。"""

    def districts(self, keywords: str, subdistrict: int = 1) -> list[District]:
        """区县 → 下级行政区划列表（含 name/adcode/level/center）。"""

    # ---- 组合接口 ----
    def enrich(self, records: list[dict], name_field: str,
               area_field: str, street_field: str) -> pd.DataFrame:
        """批量补全，返回资产一同构的 DataFrame。"""

    def build_admin_table(self, areas: list[str]) -> pd.DataFrame:
        """批量构建行政区划映射，返回资产二同构的 DataFrame。"""

    # ---- 判定 ----
    def is_trusted(self, hit: GeoHit, area_name: str) -> tuple[bool, str]:
        """两级可信判据。返回 (是否可信, 不可信原因)。"""
```

`GeoHit` 至少含：`lng, lat, level, adcode, district, formatted, query`。

## 3 必须实现的工程要求

**以下每一条都来自实测失败，不是理论推测。** 缺任何一条都会导致结果错误或流程卡死。

### 3.1 网络层

| # | 问题 | 现象 | 方案 |
|---|---|---|---|
| 1 | `urllib` 的 `timeout` **不覆盖 DNS 解析阶段** | DNS 卡住时进程无限等待（曾挂死 36 分钟，CPU 仅用 25 秒） | 每个请求放进 **daemon 线程**，`thread.join(timeout)` 硬超时；超时即放弃并把线程留作 daemon |
| 2 | DNS 可能返回假 IP 并失效 | 解析到 `198.18.0.x`（代理层）后请求挂死；某次切换后变成真实 IP `106.11.28.33` | 缓存 `getaddrinfo` 结果；连续失败 2 次即 `clear_dns_cache()` |
| 3 | Windows 下 `curl.exe` 不可用 | `schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS (0x8009030e)` | **只能用 Python `urllib`**（OpenSSL 栈） |
| 4 | 部分抓取工具会拒绝该域名 | `web_fetch` 报 "resolves to a non-public IP address" | 同上，走 Python |
| 5 | 瞬时错误码需要重试 | `10021`（QPS 超限）929 次、`30001`（引擎异常）609 次 | 建立 `TRANSIENT = {10021, 30001, 10004, 10022, 10029, 30000}`，退避重试 + 自适应降速 |

### 3.2 配额与选型

| # | 问题 | 方案 |
|---|---|---|
| 6 | 关键词搜索个人配额仅 **5,000 次/月**，8,782 条要跑两个月 | **必须用地理编码**（同属「基础 LBS 服务」池，150,000 次/月）。接口：`/v3/geocode/geo` |
| 7 | QPS 超限 | 起始间隔 0.15s；失败时间隔 ×1.6 递增（上限 1.5–2.0s），连续成功后 ×0.9 回降 |
| 8 | 中断会重复消耗配额 | **缓存 + 输出 CSV 双保险断点续跑**；缓存键 `f"{路径}|{city}|{address}"` |

### 3.3 查询构造

| # | 问题 | 现象 | 方案 |
|---|---|---|---|
| 9 | 不传 `city` 限定会跨省错配 | `江南新区玉龙路766号` → 建邺区（南京）；`双江街道沙滨路436号` → 沙坪坝区（应为云阳） | **`city` 传区县 adcode** |
| 10 | 地址缺「重庆市」前缀会飘到外省 | 同上 | 构造查询串时补前缀 |
| 11 | 单一查询式命中率不足 | 单策略 68~72% | **级联三种查询式**，命中即可用 level 即停：<br>① `重庆市{区县}{街道}{名称}`<br>② `重庆市{区县}{名称}`<br>③ `{名称}`（adcode 限定）<br>并集可达 **85%**（首轮），扩大变体后 **84~100%** |

### 3.4 行政区划

| # | 问题 | 现象 | 方案 |
|---|---|---|---|
| 12 | 街道级**没有边界多边形** | `extensions=all` 时街道的 `polyline` 为空 | 只能用 `center`；**不可做"点在面内"判定** |
| 13 | 区划树**缺「渝北区」「江北区」节点** | 其 42 个街道全挂在「两江新区」(500157) 下 | 查询时对渝北/江北/北碚启用**父区回退** |
| 14 | 关键词搜「江北区」会命中**宁波市江北区** | 8 条街道坐标落在经度 121.5（浙江） | **必须加重庆 bbox 过滤**（105.1–110.4E / 28.0–32.5N） |
| 15 | 区划树缺 8 个单元（渝北统景镇/兴隆镇等） | 查不到 | 用地理编码 `重庆市{区县}{街道}` 兜底取中心点 |
| 16 | 征收处「街道」字段混有门牌 | `高阳镇高乐路369号` | **前缀匹配**：取最长可匹配的行政区划名 |

### 3.5 坐标与可信判定

| # | 问题 | 现象 | 方案 |
|---|---|---|---|
| 17 | 房交坐标是 **CGCS2000/WGS84**，高德是 **GCJ-02** | 原始中位距离 576m；转换后 249m；<100m 样本从 **0 → 20** | 距离计算前必须 `wgs2gcj()`（本地实现，不用配额） |
| 18 | **`level` 单独不可信** | `level=住宅区` 也可能在**新疆伊宁**（`建银小区`）、**澳门**（`福康大厦`） | **两级判据**：① level 白名单 ② 高德区县 与登记区县一致（含别名/等价类/功能区） |
| 19 | 面坐标几何损坏 | 113 条包围盒 >1000m（最大 171 km），质心不可信 | 包围盒对角线 ≥1000m 判为不可信 |
| 20 | 只查 level 可信率虚高 | 84.2% → 加区县一致性后 **78.7%** | 必须两级都过 |

## 4 可信判据（必须实现）

```
可信 = (level ∈ {住宅区, 兴趣点, 门址, 门牌号, 单元, 商务大厦})
       AND (高德区县 ≡ 登记区县)
       AND (坐标在重庆辖区 bbox 内)
       AND (房交侧：面坐标包围盒对角线 < 1000m)
```

区县"一致"包含三类等价，缺一即误判：

| 类型 | 例 |
|---|---|
| 别名 | 石柱县 ≡ 石柱土家族自治县 |
| 等价类 | **两江新区 ≡ 渝北区 ≡ 江北区**（用户确认，且高德区划模型亦如此） |
| 功能区代管 | 蔡家岗街道、童家溪镇 行政属北碚区，实际由两江新区直管 |

## 5 已知的非文档化 API 行为

| 行为 | 说明 |
|---|---|
| 地理编码一次返回多候选 | 按 `level` 优先级取最优：`住宅区 > 门牌号 > 门址 > 兴趣点 > 单元 > 道路 > 区县` |
| `level` 取值 | 实测出现：`住宅区 / 兴趣点 / 门址 / 门牌号 / 单元 / 乡镇 / 村庄 / 道路 / 区县 / 省 / 公交地铁站点 / 未知` |
| 区划接口一次返回整区县下级 | 1 次调用可覆盖 20~52 条街道记录，不必逐街道查 |
| 区划有生效日期 | 永昌街道 **2025-12-24** 由中山路街道拆分设立；物业处数据（`gmt_create` 2025-11-05）早于拆分，两边都对但时点不同 |
| 房交「点位坐标」不是点 | 是线段/边界顶点（12% 含多个点），不能当定位点用 |

## 6 落地建议

| 项 | 建议 |
|---|---|
| 模块位置 | `f2s2g/src/external/` 下：`client.py`（网络层）/ `geocode.py`（补全）/ `admin.py`（区划）/ `trust.py`（判定） |
| 配置 | key、qps、超时、bbox、level 白名单、区县等价表全部外置到 `configs/external.yaml` |
| 缓存 | 默认开启，路径可配；缓存键必须含 `city` |
| 降级 | 无网/无 key 时读取已有资产 CSV，不报错退出 |
| 测试 | 用 20 条已知样本做回归，断言 `(lng, lat, level, 可信)` 与资产一一致 |

---

## 7 明确不做

1. 不用关键词搜索接口（配额不够）
2. 不用坐标转换 API（本地实现零配额）
3. 不把不可信坐标用于距离判定、作图边、进特征
4. 不用外源数据反推任何金标准对端
5. 不假设街道中心点等于辖区范围
